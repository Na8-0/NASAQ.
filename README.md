# موقع نَسَق | دليل النشر والإضافة

## الملفات
- `index.html`: الموقع نفسه.
- `works.json`: قائمة الأعمال المعروضة.
- `works/`: صور وفيديوهات الأعمال.

## أولًا: النشر على GitHub Pages
1. أنشئي مستودعًا جديدًا (Repository) على GitHub بحالة **Public**، واسمه مثلًا `nasaq`.
2. ارفعي كل محتويات هذا المجلد (الملفات والمجلد `works`) إلى المستودع: **Add file ← Upload files**، واسحبي الملفات والمجلد معًا. الأسهل من جهاز كمبيوتر.
3. من **Settings ← Pages**: اختاري **Deploy from a branch**، والفرع **main**، والمجلد **/(root)**، ثم **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-المستخدم.github.io/nasaq/`

## ثانيًا: إضافة الأعمال من الموقع (لك فقط)
زر الإضافة غير موجود للزوار. يظهر فقط عند فتح الرابط وفي آخره `#admin`، ولا يعمل إلا بمفتاح خاص بك.

**إنشاء المفتاح (مرة واحدة):**
1. GitHub ← صورتك ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. **Repository access**: اختاري **Only select repositories** ثم مستودع الموقع فقط.
3. **Permissions ← Repository permissions ← Contents**: اختاري **Read and write**.
4. حددي مدة الصلاحية (مثلًا 90 يومًا) ثم **Generate token**، وانسخي المفتاح.

**الاستخدام:**
1. افتحي `https://اسم-المستخدم.github.io/nasaq/#admin`
2. اضغطي **+ إضافة عمل**. في أول مرة تدخلين اسم المستودع (`اسم-المستخدم/nasaq`) والمفتاح، ويُحفظان على جهازك.
3. اختاري القسم، واكتبي الاسم والوصف، وارفعي الصور (الأولى هي الغلاف) أو فيديو MP4، ثم **نشر العمل**.
4. يظهر العمل في الموقع بعد دقيقة أو دقيقتين.

**للحذف:** افتحي العمل من الموقع (مع `#admin`) واضغطي **حذف العمل**.

## ملاحظات أمان
- لا تشاركي المفتاح مع أحد ولا تكتبيه داخل الملفات. إذا ضاع أو شككتِ فيه، احذفيه من إعدادات GitHub وأنشئي غيره.
- أي شخص يضيف `#admin` للرابط لن يستفيد شيئًا بدون المفتاح.

## تغيير رقم الواتساب
افتحي `index.html` وابحثي عن `var WA=` وغيّري الرقم بصيغة دولية بدون `+`.
